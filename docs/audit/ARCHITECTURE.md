# Architecture audit

Scope: the structure of the gamehandler workspace — the layering the project
states and whether it holds, module organisation against the sizes the tree
actually has, duplication, abstraction quality, the error-handling architecture,
testability, and whether the codebase's unusually dense explanatory comments are
accurate and load-bearing or have drifted. The subject is both crates —
`crates/core` (`gamehandler-core`) and `crates/app` (`gamehandler`) — plus the
gate scripts and the reference Python implementation under `gamehandler/` where
a finding's answer turns on parity.

The layering claim is `DECISIONS` D-03: `crates/core` is pure, synchronous and
GUI-free, and must never depend on libcosmic or iced. That claim was verified
mechanically rather than assumed (see "Verified sound"). The parity claim is
D-01: the Rust port is measured against the Python 3 + PySide6/QML reference, so
where a defect exists in both, this document says so — a faithful copy of a
reference bug is a different finding from a port-introduced regression, and the
distinction decides whether the fix is a divergence or a bug fix.

This audit inherits one rule from `docs/audit/BASELINE.md:193-200`, adopted there
after a fabricated observation was recorded and withdrawn: **text read off an
image is not evidence.** Every claim below is either a line read from source, or
a count produced by running something and reading the raw exit status. Where a
prior report's claim did not survive re-measurement it is marked withdrawn rather
than repeated.

The comment findings are grouped last but are not the least of them. This
codebase's comments are load-bearing: several of its most confident paragraphs
are the *only* record of why a decision was made, and the project has already
been burned by a comment that confidently stated something false. The findings
below are therefore not "the comments are verbose" but "these specific
paragraphs are false, and here is the measurement".

## Verified sound

Each item below was checked and confirmed during this audit, and is cited so it

- **The stated layering holds.** `crates/core/Cargo.toml` declares only `serde`, `serde_json`, `tar`, `xz2`, `bzip2`, `flate2`, `rustix` — no libcosmic, no iced, no `cosmic`, no `winit`.
